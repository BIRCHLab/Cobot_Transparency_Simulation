# Cobot_Transparency_Simulation
Companion repository to go along with the paper "Simulation of Transparent Interactions: Towards Improved Upper-Limb Rehabilitation with Cobots" presented at the AACC Modeling, Estimation and Control Conference (MECC) in October 2026. 

Use the enivronment.yaml file to make a new conda environment, and run "simulate_mecc_results.py" to run the simulations from the paper!
